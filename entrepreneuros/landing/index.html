FAQ

Questions fréquentes

L'app est vraiment gratuite ?

Oui, totalement. Le code est open source sous licence MIT. Si tu utilises le mode "Clé API", tu paies directement ton provider (Anthropic ou OpenAI) — généralement quelques centimes par génération. Le mode "Web" passe par ton compte gratuit claude.ai/chatgpt.com. Le mode "Local" via Ollama est 100% gratuit.

Quelle différence entre les 3 modes IA ?

Clé API : streaming live, qualité max, ~0,5-5 centimes par génération. Le plus fiable.
Web direct : utilise ton plan gratuit/payant existant sur claude.ai ou chatgpt.com. Plus lent (scrape DOM), peut casser quand le site change.
Local (Ollama) : 100% offline, gratuit, mais qualité moindre (modèle 3-7B vs Claude 4.7).

Mes données sont-elles envoyées quelque part ?

Aucune télémétrie. Tes documents générés et ton profil restent dans ~/Library/Application Support/EntrepreneurOS (Mac) ou %APPDATA%\\EntrepreneurOS (Windows). Les clés API sont chiffrées AES-256-GCM. Si tu utilises une clé API, le contenu de tes prompts transite vers Anthropic/OpenAI — c'est inévitable. En mode local (Ollama), rien ne sort de ta machine.

Ça marche pour mon type d'activité ?

L'app supporte 13 modèles d'entreprise : SaaS, service B2B, service B2C, e-commerce, commerce physique, restauration, artisanat, coaching/formation, création de contenu, agence, marketplace, profession libérale, freelance. Choisis ton modèle dans Paramètres → Profil et tous les outputs s'adaptent.

Mac uniquement ?

Non. L'app fonctionne sur macOS (.dmg) et Windows (.exe). Builds Linux (.AppImage) disponibles aussi. Apple Silicon et Intel supportés.

Je peux personnaliser les prompts générés ?

Tu peux affiner après coup avec la zone "Affiner ce document" en bas de chaque sortie : tape une instruction comme "raccourcis l'exec summary" ou "ajoute une section sur les risques juridiques", et l'IA régénère. L'historique des affinages est conservé.

Les factures sont conformes à la loi ?

L'app génère un récapitulatif + une checklist des mentions légales obligatoires pour le pays concerné (France, Belgique, Suisse, Canada, Maroc, UE intracom). Pour le PDF final légal, fais valider par ton expert-comptable — c'est un assistant, pas un substitut.
